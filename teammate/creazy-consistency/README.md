# creazy-consistency — 팀원 산출물

제공된 `c71a0f8` ZIP의 코드 스냅샷이다. 기준 자료(refset) → 제작 명세(spec) → 결과 검수(check) → 복원/수정과 평가(bench)의 흐름과 FastAPI 데모, 전체·부품·인쇄 복원 탐색 코드를 포함한다.

공개본에서 고객 및 기본 샘플 이미지를 제외했다. 원본 저장소처럼 샘플 버튼만으로 바로 실행된다고 보장하지 않는다. 상세한 [실행 조건](../../docs/reproduction.md)과 [결과·통합 인사이트](../../docs/team-integration.md)를 참고한다.

`tests/`에는 합성 자료 기반 테스트와 원본 데이터가 필요한 테스트가 함께 있다. 전체 테스트 통과와 실제 제품 복원 품질은 별개다.
