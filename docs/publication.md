# 공개 범위와 정리 이력

## 포함

- 실험·시제품 실행 소스, 기존 테스트, 의존성/프로토콜의 공개 가능한 부분
- Run 01–31 회고를 공개용으로 재구성한 상세 README
- 팀원 ZIP의 코드 구조와 최종 판정의 요약
- 소스 출처와 SHA-256 매니페스트

## 제외

- 고객 원본·생성 이미지·영상, CS CSV/상담·고객별 대응표, 비공개 정답/라벨/작업 이력
- 기업 저장소/스토리지의 직접 이미지 URL, 임시 생성물 다운로드 주소
- 회의 음성·자동전사, 개인 첨부파일/로컬 계정 경로
- 실행에 필요하지 않은 다운로드된 Hunyuan 서비스 소스 사본(원래 실험 프로토콜은 유지)
- API 자격증명과 `.env`, 모델 체크포인트/LoRA 가중치, 다운로드 부분 파일, 가상환경/캐시/바이너리
- PPT/PDF에 포함된 고객 이미지, 공개 권한을 별도로 확인하지 못한 ZIP 기본 사진

제외한 자료가 없다는 사실을 실패 결과의 삭제나 성공률 변경으로 처리하지 않았다. 원래 결과는 조건·한계와 함께 README에 남겼다. 공개 입력 예제가 부족한 모듈은 실행 안내에서 소스 보관 상태임을 명시했다.

## 원본에 가한 변경

1. 두 코드베이스를 `research/`, `teammate/creazy-consistency/`로 분리했다.
2. 개인 Mac의 절대 경로를 `__file__` 기준으로 바꾸고, 비공개 입력 URL/경로는 `LOCAL_INPUT_REQUIRED`로 치환했다.
3. 노트북 실행 출력·실행 번호를 제거했다.
4. API runner의 기존 단위 테스트가 개인 실사 파일에 의존하던 부분을 임시 합성 이미지로 바꿨다. 요청 계획/예산/재개 관련 테스트의 검증 의도는 유지했다.
5. 원본 문서의 과거 지시문/내부 링크 대신 공개 README와 실행 경계 문서를 작성했다. 기존 알고리즘을 개선하거나 새 품질 실험을 수행하지 않았다.
6. Hugging Face Diffusers에서 파생된 학습 코드의 저작권 헤더를 유지하고 라이선스를 첨부했다.

## 출처

- 팀원 스냅샷: `creazy-consistency-c71a0f8.zip`, 원본 commit `c71a0f84eeded2c059a5fa449f8f271b1ae04e92`.
- 우리 측 작업: Run 31 종료 시점의 기업과제 작업 폴더.
- [소스 매니페스트](source-manifest.json)는 포함한 원본 파일의 해시와 공개본 경로를 기록한다. 패키징 중 변경된 파일은 공개본 해시가 다르다.

공개 GitHub 저장소라는 이유만으로 포함된 모든 작업에 임의의 오픈소스 라이선스를 부여하지 않았다. 자체/팀원 코드의 별도 재사용 허락은 권리자에게 확인한다. 이미 라이선스가 있는 외부 코드는 해당 조건을 따른다.
